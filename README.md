KELAPA YARD — a round-based tactical FPS in three.js: a tropical walled yard with three lanes, two bomb sites (KIOS and WARUNG), four bots that patrol, hold and shoot back, bomb plant/defuse, a per-round economy and buy menu, three weapons and a grenade.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
